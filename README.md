# Comparative Analysis of Primate Insulin Sequences using BioPython

## Overview

This project performs a comparative bioinformatics analysis of insulin protein sequences from multiple primate species.

The workflow includes:

* Retrieval of insulin protein sequences from UniProt and NCBI
* Amino acid composition analysis
* Protein physicochemical property calculation
* Conservation analysis
* Identification of variable amino acid positions
* Similarity matrix generation
* Heatmap visualization
* Phylogenetic tree construction

## Species Included

* Homo sapiens
* Pongo abelii
* Pan troglodytes
* Nomascus leucogenys
* Hylobates moloch

## Tools Used

* Python
* BioPython
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy

## Key Findings

* Insulin is highly conserved among primates.
* 106 out of 110 amino acid positions were fully conserved.
* Overall conservation was approximately 96.36%.
* Variable positions were observed at residues 2, 12, 23, and 61.
* Position 23 exhibited the highest variability.
